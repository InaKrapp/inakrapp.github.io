To render the site and push it to github, run this in the terminal:

quarto render
git add docs
git commit -m "Publish site to docs/"
git push

To add a preview to a presentation, make sure the yaml header of the index.qmd contains:
image: "thumbnail.png" 
and an image named thumbnail.png is in the same directory.
Also, the image has to be roughly 1280 to 720 or parts of it will get cut off.
